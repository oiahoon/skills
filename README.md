# Skills

我的个人技能库。

| 技能 | 用途 |
| --- | --- |
| [Fancy-VanGogh](skills/fancy-vangogh/SKILL.md) | 把照片或文字场景转绘为以漫画人物、成组环境笔触和相互衔接的色面构成的插画。 |

在支持技能的环境中导入 `skills/fancy-vangogh/`，保留目录结构。使用时可以提供照片或文字场景，也可以附上有权使用的风格参考图。仅提供文字或照片时，技能会使用仓库里的文字画法规则。

公开版包含规则、图标和原作出处。原作者为 Alireza Karimi Moghaddam。 [原作索引](skills/fancy-vangogh/references/artwork-sources.md)
